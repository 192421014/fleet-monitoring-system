# Intelligent Public Transportation Fleet Monitoring System

## Project Description

A full-stack fleet monitoring platform for monitoring public transportation buses.

## Features

- Bus monitoring
- Fuel monitoring
- Passenger monitoring
- Bus location
- Delay monitoring
- Fleet dashboard

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- Git
- GitHub
- Docker
- Docker Compose
